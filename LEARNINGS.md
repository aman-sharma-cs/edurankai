
# Learnings – Student Management System

During the development of this project, I learned and implemented the following concepts:

## 1. Backend Development

- Developed REST APIs using Java and Spring Boot.
- Understood the Controller-Service-Repository architecture.
- Used Spring Data JPA for database operations.
- Implemented CRUD operations for student records.
- Used DTOs to transfer request data between the frontend and backend.

## 2. Database Management

- Integrated PostgreSQL with Spring Boot.
- Designed a student database table.
- Implemented primary key and unique email constraints.
- Used Hibernate for ORM and entity management.
- Implemented soft deletion to preserve student records.

## 3. Validation and Exception Handling

- Implemented input validation using Jakarta Validation.
- Validated email format and phone number.
- Prevented duplicate email registration.
- Created custom exceptions for student not found and duplicate email.
- Implemented centralized exception handling using `@RestControllerAdvice`.

## 4. Frontend Development

- Built the user interface using HTML and CSS.
- Used JavaScript to communicate with backend REST APIs.
- Practiced Fetch API and async/await.
- Implemented dynamic student listing, searching, and filtering.
- Connected dashboard statistics with backend data.

## 5. Testing

- Used JUnit and Spring Boot Test for automated testing.
- Tested successful student creation.
- Tested invalid email validation.
- Tested duplicate email handling.
- Tested student update functionality.

## 6. Key Takeaway

This project helped me understand how frontend, backend, REST APIs, and a relational database work together in a full-stack application. It also improved my understanding of API integration, validation, exception handling, and automated testing.
